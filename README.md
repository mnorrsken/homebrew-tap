# mnorrsken Homebrew tap

```sh
brew install mnorrsken/tap/scn3
```

| Cask | What it is |
| --- | --- |
| [scn3](https://github.com/mnorrsken/scn3) | Disk usage as a sunburst chart |

The apps here are not signed with an Apple Developer ID yet. Each cask removes the quarantine flag after install, so macOS opens the app without the "can't be verified" block. Only install from this tap if you trust it.

The release workflow of each app updates its cask.
